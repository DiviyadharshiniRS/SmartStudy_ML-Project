# SmartStudy: Student Performance Prediction using Machine Learning

This project predicts student GPA using machine learning techniques and provides personalized improvement suggestions.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Machine Learning Methods
- K-Means Clustering
- Linear Regression

## Features
- Student GPA prediction
- Behaviour clustering
- Performance classification
- Improvement suggestions

## Results
The model achieved an R² score of approximately 0.95, indicating strong prediction performance.
